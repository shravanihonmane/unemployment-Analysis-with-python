# unemployment-Analysis-with-python

## Objective
Analyze unemployment-rate data, visualize trends and compare unemployment before and during the COVID-19 period.

## Dataset
Use the unemployment CSV provided by CodeAlpha. Put it in this folder and update the filename in `unemployment_analysis.py` if necessary.

## Libraries
pandas, matplotlib.

## Run
```bash
pip install -r requirements.txt
python unemployment_analysis.py
```

## Outputs
- Monthly unemployment trend graph
- COVID-period comparison
- Highest observed unemployment record
- Regional analysis when a region/state column exists
